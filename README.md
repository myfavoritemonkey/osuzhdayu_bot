# Бот «Осуждаю»

Telegram-бот на Go отвечает на сообщения с «осуждаю» короткой остроумной
репликой, сгенерированной через DeepSeek API. Дополнительно можно включить
осторожный режим диалога с обращениями к боту.

## Запуск в Docker

`config.cfg` не включается в Docker-образ: его нужно хранить на хостинге и
подключать как внешний файл только для чтения.

Соберите и запустите контейнер через Compose:

```bash
docker compose up -d --build
```

В `docker-compose.yml` конфигурация подключается так:

```yaml
volumes:
  - ./config.cfg:/app/config.cfg:ro
```

Посмотреть журнал:

```bash
docker logs -f osuzhdayu-bot
```

Или запустите образ вручную:

```bash
docker build -t osuzhdayu-bot .
docker run -d \
  --name osuzhdayu-bot \
  --restart unless-stopped \
  -v "$PWD/config.cfg:/app/config.cfg:ro" \
  osuzhdayu-bot
```

Если файл лежит в другом месте, смонтируйте его в контейнер и задайте путь
через переменную `CONFIG_PATH`.

## Запуск без Docker

Нужен Go 1.22 или новее:

```bash
go run .
```

По умолчанию программа ищет `config.cfg` в текущем рабочем каталоге. Другой
путь можно указать через `CONFIG_PATH`:

```bash
CONFIG_PATH=/path/to/config.cfg go run .
```

## Конфигурация

Скопируйте `config.cfg.example` в `config.cfg` и заполните токен Telegram-бота
и ключ DeepSeek. Файл уже добавлен в `.gitignore`, поэтому секреты не должны
попасть в репозиторий.

Основные параметры:

- `trigger_words` — список слов или фраз через запятую.
- `respond_to_direct_messages` — `true` включает обработку reply на сообщения
  бота, сообщений с его `@username` и обращений со словами из
  `bot_reference_words`.
- `bot_reference_words` — формы слова «бот», через запятую.
- `context_messages_after_reply` — сколько следующих сообщений анализировать в
  контексте после ответа бота.
- `context_reset_seconds` — время жизни контекста после ответа.
- `cooldown_seconds` — пауза между ответами в одном чате.
- `system_prompt` — стиль ответов.
- `model` — модель DeepSeek.
- `relay_forwarded_messages` — обрабатывать пересланные сообщения из личных
  сообщений и публиковать ответы в общем чате.
- `relay_chat_id` — ID общего чата для режима пересылки.

## Настройка Telegram-группы

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В @BotFather выполните `/setprivacy` → выберите бота → `Disable`, либо
   добавьте бота администратором, чтобы он видел обычные сообщения группы.
3. Добавьте бота в нужную беседу.
4. Напишите в группе сообщение с «осуждаю» для проверки.

Для режима пересылки сначала запустите бота, убедитесь, что Privacy Mode
отключён, отправьте исходное сообщение в группу, а затем перешлите его боту в
личные сообщения. Бот ищет оригинал по ID пересылки или по точному тексту в
кэше последних 500 сообщений группы.

Бот использует Telegram long polling, поэтому отдельный сервер и webhook не
нужны. Он игнорирует сообщения от других ботов, чтобы не создавать цепочки
ответов. Если DeepSeek или Telegram временно недоступны, ошибка записывается в
журнал, а процесс продолжает работу.
